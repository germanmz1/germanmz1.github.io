Wine Quality Prediction

Proyecto de Machine Learning para predecir la calidad de vinos usando Random Forest y análisis exploratorio de datos.

Python Machine Learning EDA Random Forest

Overview

El objetivo de este proyecto es predecir la calidad de vinos tintos utilizando variables químicas del dataset Wine Quality.

Se realizó un análisis exploratorio de datos, ingeniería de variables y entrenamiento de modelos de machine learning.

Dataset

El dataset contiene información química sobre vinos tintos, incluyendo:

  • Acidez fija
  • Acidez volátil
  • Ácido cítrico
  • Azúcar residual
  • Alcohol

Exploratory Data Analysis

Se analizaron distribuciones, correlaciones y relaciones entre variables.

Machine Learning Model

Se entrenó un modelo Random Forest optimizado mediante GridSearch.

Accuracy: 0.79

ROC AUC: 0.79

Conclusion

El modelo logró un accuracy cercano al 80%. Se observó que variables como alcohol y acidez volátil tienen fuerte influencia en la calidad del vino.
